SwiftUI, Swift 6.3, local-first, no network (a NetworkSilenceTests harness enforces it; `grep URLSession|import Network` in app/Sources and Packages returned nothing). ## Architecture
Three Swift layers plus tooling:
- `app/Packages/PraxmodoroCore` - pure deterministic engine: Session, SessionReconstruction (replay from events), SessionTimeline, TimingPolicy (custom policies, long-break cadence), block-end behaviours, adjustments, auto-return. Time is derived from canonical timestamps; ticks are presentation only.
- `app/Packages/PraxmodoroStore` - LocalStore (SwiftData over SQLite, `praxmodoro.store`): append-only event log (StoredEvent with orderIndex), sessions, review timeline.
- `app/Sources` - app: AppModel.swift (815 lines, graph god node, 148 edges: the single observable model, intents, lifecycle, replay, sound/notification scheduling), PraxmodoroApp.swift (scenes: main window, MenuBarExtra, floating capsule, Settings), SessionReplay/SessionSnapshot (store->Core replay, pure), SoundDirector/NotificationDirector (cue scheduling behind seams, anchored on canonical instants), Preferences (UserDefaults seam: RhythmPreferences, SoundPreferences), CapabilityRegistry/Provenance (internal keys), DesignTokens + Generated (from scripts/generate-design-tokens.mjs, OKLCH to sRGB), SurfacePalette, KeyboardMap, Checkin, CompanionField (FieldPhysics/FieldModel/CompanionFieldView, golden-tested against design-mocks companion-physics.js).
- Surfaces: Initiate, Focus, Break, Checkin, Review, MenuBarPopover, FocusCapsule, ReturnOverlay, SettingsSurface, RhythmPane, SoundNotificationsPane.
- Resources/Sounds: five synthesized wavs (scripts/generate-sounds.mjs).
- Project generated by XcodeGen from app/project.yml (Praxmodoro.xcodeproj is gitignored); targets Praxmodoro, PraxmodoroTests, PraxmodoroUITests; ad-hoc signing; hardened runtime on app, off on tests; warnings are errors.

## Main flows
initiate (task + first step + policy) -> focus (companion field, phases) -> check-ins (1-4 keys) -> block end (prompt-first default, per Preferences.swift:17 `blockEnd = .promptFirst`) -> break (rewind/forward +-1 min as recorded adjustment events) -> auto-return/return overlay -> review timeline. Relaunch/wake reconstruct from the event log.

## Data and state
SQLite store via SwiftData (no VersionedSchema yet, issue #37); UserDefaults for rhythm/sound prefs; no Keychain, no network, no telemetry. Event log is append-only; orderIndex is derived by fetching (issue #40).
