# Audit reports (2026-10)

These files come from a repository audit run from 2026-10-02 to 2026-10-11 and accompany PR #63 (`fix/audit-2026-10`), which was merged after PR #62 and supersedes draft PR #60. `UNDERSTANDING.md` describes the app's purpose, architecture, flows and risks as found at audit time; `SETUP.md` gives the verified build, test and run steps; `GRAPH_REPORT.md` is the generated code/document knowledge-graph summary; `FIXES.md` records what the audit branch fixed and how it was checked; `REVIEW.md` is the independent review of those fixes (later review items were addressed in follow-up commits on the same PR). This repository is public, so security details (security reports, raw findings and owner notes) are kept privately by the owner and are not included here.
