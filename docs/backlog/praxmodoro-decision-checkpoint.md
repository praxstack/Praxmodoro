# Praxmodoro decision checkpoint

Open the local form:

```sh
open /Users/prax/Developer/Praxomodoro/docs/backlog/praxmodoro-decision-checkpoint.html
```

Choose one option, read it, tick the separate confirmation box, and select **Record decision locally**. The page then shows a JSON receipt. Select **Download receipt JSON** and send that file or its contents back in chat.

The receipt proves one local choice. It does not prove implementation, tests, merge, signing, notarization, packaging, release, or agent execution. Those claims need separate evidence.

This checkpoint does not use Dcanvas, agent-send routes, network requests, cookies, `localStorage`, or `sessionStorage`. Reloading the page returns it to `PENDING`.
