  invalidated → correct the receipt or rerun the signed test gate.
- If `git diff --cached --check`, strict OpenSpec validation, or PRD parsing fails before commit,
  invalidated → fix and re-audit.
- If XcodeGen changes any generated project file before or immediately after commit, invalidated →
  investigate and review the generated diff.
- If any allowlisted path remains dirty immediately after commit, invalidated → stop before atom
  1.2 and reconcile the residue.
- If the commit contains any path outside the allowlist, invalidated → stop integration and repair
  history safely.
